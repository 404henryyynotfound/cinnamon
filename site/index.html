Get started

Install it your way

One app, three package managers. Every download comes from a public GitHub release.

npm
npm install -g cinnamon-gui

Then run cinnamon. The launcher verifies checksums for you.

apt
curl -fsSL https://github.com/404henryyynotfound/cinnamon/releases/latest/download/cinnamon-linux-x64.deb -o cinnamon.deb
sudo apt install ./cinnamon.deb

Use arm64 instead of x64 on a Raspberry Pi.

snap
sudo snap install cinnamon-tasks

Strictly confined and auto-updating through Ubuntu App Center.

More than a task manager

Everything happening on your machine

▤

Live processes

Sortable, searchable process table with CPU, memory, uptime and command line — refreshed automatically.

⏻

Take control

Pause, resume, interrupt, terminate or kill processes, change priority, inspect open files, and renice. Every action asks for confirmation first.

◈

Real-time graphs

Inline SVG charts for CPU, memory, disk and network, plus per-process breakdowns and activity heatmaps.

✦

Explainable AI

Local diagnostics rank findings with evidence: runaway processes, memory pressure, disk pressure and zombies.

☁

Optional BYOK AI

Add your own OpenAI-compatible endpoint in Settings. Your key stays on your device; local AI is the fallback.

◉

Watchers

Set thresholds for any process or resource and keep an alert log. No daemon, no account, no cloud.

≡

Two changelogs

Read bundled release notes in the app, or pull the latest GitHub releases with one click.

⇩

Reports & exports

Export the current table as CSV or Markdown, or build a full JSON report with top CPU/memory, group totals and AI findings.

⌘

Focus & keyboard

Pin processes to follow them across refreshes, switch between flat and parent/child tree views, and drive everything from the command palette.
